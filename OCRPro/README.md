# OCRPro (Objective-C)

一个可直接打开的 Xcode iOS OCR 示例工程，使用 Apple Vision 实现离线文字识别，适合商业化二次开发。

## 功能
- 拍照识别 / 相册导入
- 中文 + 英文识别
- 结果页展示与一键复制
- UIKit 原生 UI，结构清晰

## 运行
1. 用 Xcode 15+ 打开 `OCRPro.xcodeproj`
2. 修改 Bundle Identifier（`com.example.ocrpro`）
3. 真机运行（相机功能需真机）
