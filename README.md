# UnitConverterPro (Objective-C)

一个偏商业化视觉风格的单位换算 App 示例，使用 UIKit + Objective-C 实现，包含：

- 多分类单位（长度 / 重量 / 温度 / 体积）
- 双列选择器 + 即时换算
- 历史记录（本地持久化、可清空）
- 卡片式 UI、阴影与层级
- iOS 13+ Scene 生命周期

## 上架建议（避免 4.2）

为了降低“功能过于简单”风险，建议继续扩展：

1. 增加专业场景：烹饪、健身、工程、摄影单位包。
2. 增加汇率与时区换算（联网能力 + 离线缓存）。
3. 增加收藏夹、固定组合、iCloud 同步。
4. 增加 Widget、Siri Shortcuts、Spotlight 快捷操作。
5. 增加新手引导、隐私说明页、订阅/高级功能（如批量换算、历史分析）。

> 当前仓库提供的是可继续工程化的基础版本，适合快速起步并迭代到可上架质量。
