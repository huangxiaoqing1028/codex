# 可运行 Xcode 工程（Objective-C）

打开 `HeavySweep/HeavySweep.xcodeproj`，选择 iOS Simulator 后直接 Run 即可。

## 已补齐模块
- 启动页（LaunchScreen.storyboard）
- 主菜单（开始征战、设置、离线收益展示）
- 战斗场景（SpriteKit）
- 设置（音效、震动、隐私说明）
- 本地存档（金币、最高分、成就、离线时间）
- 本地成就（达到指定分数解锁）
- 离线经济（按离线秒数结算金币，上限 2 小时）
- 审核文案模板（设置页隐私说明）

## 审核说明模板（可复制到 App Review Notes）
1. 本应用为单机游戏，无账号体系，无用户上传内容。
2. 不采集个人身份信息，不进行跨 App 追踪。
3. 不请求通讯录、定位、相册等与核心玩法无关权限。
4. 主要差异化点：重度成长向分数循环、离线收益、成就系统和本地化题材表现。
